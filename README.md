# Basketball Scoreboard

A simple basketball scoreboard built with HTML, CSS, and JavaScript.

## Features
- Score tracking for HOME and GUEST teams (+1, +2, +3)
- Game timer with start, pause, and reset
- Automatic highlighting of the leading team
- Reset all scores and timer
